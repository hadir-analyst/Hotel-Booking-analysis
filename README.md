# Hotel Booking Analysis | Excel

## Project Overview
This project analyzes hotel booking data using Microsoft Excel to identify booking patterns, cancellation trends, and customer behavior.

## Dataset
The dataset contains hotel booking records for City Hotel and Resort Hotel.

## Tools & Skills
- Microsoft Excel
- Data Cleaning
- Excel Formulas & Functions
- PivotTables
- Charts & Dashboards
- Data Analysis

## Project Objectives
- Analyze hotel booking trends.
- Compare cancellation rates between hotel types.
- Explore customer segments and booking patterns.
- Present business insights using charts and dashboards.

## Key Findings
- Total booking records: approximately 119K.
- City Hotel recorded more bookings than Resort Hotel.
- Online Travel Agents represented the largest market segment.
- Portugal was the most frequently recorded country in the dataset.
